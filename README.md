# RSA Neuro-Symbolic Explorer

Исследовательский прототип TKHD+MDN из раннего архива проекта. В архиве есть веб-интерфейс, Python-симулятор, два сохранённых MDN checkpoint и небольшой тестовый набор. Код модели работает с множителями **12–16 бит**; 2048-битного факторизатора здесь нет.

Подробный разбор причин и план проверок: [docs/2048_BIT_SCALING_AUDIT_RU.md](docs/2048_BIT_SCALING_AUDIT_RU.md).

## Что работает и что проверено

- Режим малых чисел запускает Python-бэкенд при наличии зависимостей и checkpoint-файлов. Найденные множители интерфейс проверяет точным произведением `BigInt`.
- Режим `2048-bit` явно сообщает `unsupported`: он не запускает модель и не рисует вымышленные шаги поиска.
- Кнопка генерации тестовой пары доступна только для малых чисел. Старые «enterprise primes» из исходного архива не были проверенными 1024-битными простыми и удалены из генератора.
- Работа checkpoint-модели и качество факторизации **не были подтверждены** в этой импортированной версии. Наличие весов не доказывает сходимость.

## Локальный запуск

```bash
npm install
python3 -m pip install -r requirements.txt
npm run dev
```

Открыть `http://localhost:3000`. Сервер вызывает `python3 solver_api.py` для запросов `/api/solve`. Файлы `mdn_p_massive.pth`, `mdn_q_massive.pth` и `rsa_massive_test.pt` получены из пользовательского архива. Загружайте их через PyTorch только если доверяете источнику; импорт и статический аудит не выполняли эти файлы.

Для проверки заявленного статуса 2048-битного режима без установки PyTorch:

```bash
python3 solver_api.py 3233 2048
```

Ожидаемый ответ: `status: "unsupported"`, `p: null`, `q: null`, пустые `steps`.

## Происхождение

Исходный архив: `rsa-neuro-symbolic-explorer.zip`, SHA-256 `5b8d52e2c59b1db40ce64a1db5c7e6e157a31515b21861d534f873a7be57ec73`. Все содержательные исходные файлы распакованы в корень репозитория. При импорте исправлены вводящее в заблуждение отображение 2048-битного режима, запуск пользовательского `N` через оболочку и зависание canvas на больших числах. Область действия этих изменений описана в аудите.
